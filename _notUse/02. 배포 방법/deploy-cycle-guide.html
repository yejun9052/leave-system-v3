빌드 & 배포 사이클

소스를 수정한 뒤 하나의 app.jar(프론트 + 백엔드 + 난독화 + 라이선스)로 빌드해, 소스 없는 패키지로 서버에 반영하는 반복 절차입니다.

빌드 산출물 app.jar 1개 서버 업로드 소스 미포함 필요 JDK 21 · Node.js

개발 PC

1 소스 수정→ 2 빌드(bootJarObf)→ 3 검증(선택)→ 4 패키징(소스 제외)

서버

5 업로드→ 6 docker compose up
경로 주의 — 빌드는 실제 프로젝트 경로에서 실행하세요. junction(C:\alwork)에서 하면 프론트(Vite) 빌드가 상대경로 문제로 실패합니다. junction 은 gradlew test 전용입니다.
개발 PC

빌드 · 패키징

JDK 21 + Node.js

1 소스 수정

프론트(frontend/src) · 백엔드(backend/src) 무엇을 고쳐도 이후 절차는 동일합니다.

2 빌드 — 프론트+백엔드 한 번에

PowerShell · 실제 경로에서$env:JAVA_HOME='C:\Program Files\Eclipse Adoptium\jdk-21.0.11.10-hotspot'
$env:Path='C:\Program Files\nodejs;'+$env:Path
cd C:\Users\picas\Desktop\김회철\annual-leave
.\gradlew.bat :backend:bootJarObf
copy backend\build\libs\backend-obf.jar backend\app.jar

이 한 번으로 프론트(vite) + 백엔드(난독화) + 라이선스가 모두 app.jar에 번들됩니다.

3 검증 (권장)

난독화가 기능을 깨뜨리지 않았는지 실제로 띄워 확인합니다.

PowerShell& "$env:JAVA_HOME\bin\java.exe" -jar backend\app.jar
# "Started LeaveManagementApplication" → http://localhost:8080
# 전체 자동점검(다른 터미널): .\scripts\smoke-test.ps1  # PASS=40 기대

4 소스 없는 배포 패키지 생성

PowerShell.\scripts\package-deploy.ps1
# → 바탕화면\annual-leave-deploy.tar.gz  (소스 미포함 자동 검증)

서버로 가는 패키지엔 난독화된 app.jar + 도커 설정만 들어갑니다. 원본 소스는 개발 PC에만 남습니다.

서버

업로드 · 재기동

Docker

5 업로드

PowerShell (내 PC)scp "$env:USERPROFILE\Desktop\annual-leave-deploy.tar.gz" 사용자명@서버IP:~/

6 재기동

서버tar xzf annual-leave-deploy.tar.gz && cd annual-leave
docker compose -f docker-compose.prod.yml up -d --build

--build 이 새 app.jar 를 반영·재시작합니다. DB 스키마 변경은 Flyway가 자동 적용(데이터 보존), .env(DB·JWT·라이선스·도메인)는 그대로 유지되어 다시 만들 필요 없습니다.

⚡

더 빠른 방법 — app.jar 만 교체

설정·구조 변화 없이 코드만 바꿨다면 패키지 전체 대신 app.jar 만 올려도 됩니다.
scp backend\app.jar 사용자@서버:~/annual-leave/backend/app.jar → 서버에서 docker compose … up -d --build

↩️

롤백 (난독화 문제 등)

일반(비난독화) 빌드로 즉시 되돌립니다: .\gradlew.bat :backend:bootJar → 생성된 jar 를 backend\app.jar 로 사용 후 재패키징·재배포.

이럴 땐?

상황대응
프론트만 수정동일하게 bootJarObf (프론트도 함께 빌드됨)
DB 스키마 변경새 Flyway 마이그레이션 추가 → 재기동 시 자동 적용(데이터 보존)
난독화 후 오류검증(3)에서 발견 → keep 규칙 보완(OBFUSCATION.md) 또는 일반 jar 롤백
라이선스서버 .env 유지 — 재배포 때 재설정 불필요
