## 1. 생일 반차 연 1회

| 항목 | 결정 |
|---|---|
| 설정 | 경조사 규정에 "연간 사용 횟수"를 둔다. 비우면 제한이 없다 |
| 생일 반차 | 1회로 설정한다 |
| 1년의 기준 | **달력 연도(1~12월)**, 휴가 시작일 기준 |
| 세는 신청 | 결재 대기 · 승인 · 취소 요청 중 |
| 넘으면 | 직원 신청과 신청 미리보기에서 **거부**한다 |
| 인사관리자 직접 등록 | **막지 않고 경고만** 보여 준다(예: "올해 이미 1회 사용했습니다") |
| 관리 화면 | 경조사 규정에 **수정 화면을 추가**하고 횟수 설정을 넣는다. 수정 API 버그(정렬 순서가 0으로 초기화됨)도 함께 고친다 |
| DB | 마이그레이션 V7: `special_leave_rules.annual_limit` 추가 |

## 2. 금지 기간 등록 시 기존 휴가 처리

### 2-1. 정책 설정 (정책 화면에서 선택, 기본값 "승인된 휴가만 유지")

| 정책 | 승인된 휴가 (취소 요청 중 포함) | 결재 대기 휴가 |
|---|---|---|
| **승인된 휴가만 유지** (기본) | 그대로 유지 | 자동 반려 |
| **모두 취소** | 자동 취소 + 연차 환원 | 자동 반려 |

- DB: 마이그레이션 V8 `leave_policy.blackout_conflict_mode`

### 2-2. 처리 대상과 방법

| 항목 | 결정 |
|---|---|
| 대상 | 금지 기간과 **하루라도 겹치는** 휴가 |
| 제외 | 금지 기간에도 신청할 수 있는 종류(`allowed_during_blackout`: 경조사·공가 등) |
| 언제 | 금지 기간을 **추가할 때**, 그리고 **기간을 늘려 수정할 때**. 정책 설정만 바꿀 때는 아무 휴가도 처리하지 않는다 |
| 사유 | "연차 사용 금지 기간 지정 (금지 기간 이름, 시작 ~ 끝)" |
| 처리자 | 금지 기간을 등록·수정한 관리자 |
| 확인 | 저장하기 전에 영향받는 휴가 명단과 건수를 보여 주고 확인을 받는다 |
| 트랜잭션 | 금지 기간 저장과 휴가 처리를 한 트랜잭션으로 한다. 메일은 커밋 뒤에 보낸다 |
| 감사 로그 | 자동 반려·취소마다 남긴다 |
| 관리 화면 | 금지 기간에 **수정 화면을 추가**한다. 수정 API 버그(시작·종료 날짜 검사 없음)도 함께 고친다 |

### 2-3. 당사자 알림 (필수)

**정책 때문에 휴가가 자동 반려·취소되면, 한 건마다 당사자에게 메일과 앱 알림을 반드시 보낸다.**

| 처리 | 메일 | 받는 사람 |
|---|---|---|
| 자동 반려 (결재 대기) | 기존 반려 메일 | 신청자 |
| 자동 취소 (승인·취소 요청 중) | 기존 인사관리자 강제 취소 메일 | 신청자, 담당 팀장은 참조(CC) |

- 메일에는 처리 사유와 금지 기간을 표시한다.
- 이메일이 없는 계정(관리 전용 계정 admin)은 앱 알림만 받는다.

### 2-4. 금지 기간을 늘려 수정할 때

| 대상 | 처리 |
|---|---|
| **새로 늘어난 날짜**와 겹치는 휴가 | 저장할 때 **지금 정책대로 바로 처리**한다 |
| **원래 기간**에 있던 휴가 (예전 정책으로 유지된 것) | 자동으로 처리하지 않고 **경고 문구**를 띄운다 |

경고 문구:
> ⚠️ 이전 정책으로 유지된 휴가는 그대로 남아 있습니다. 취소가 필요하면 관리자가 직접 취소해 주세요.

예시:
1. 10/1 "릴리스 주간" 10/19~10/23을 등록한다. 정책은 "승인된 휴가만 유지"라서 김철수의 10/20 승인 연차는 유지된다.
2. 10/5 정책을 "모두 취소"로 바꾼다. 이때는 아무 휴가도 처리하지 않는다.
3. 10/10 기간을 10/19~10/27로 늘린다.
   - 이영희의 10/26 승인 연차는 새로 늘어난 날짜와 겹치므로 **취소**된다.
   - 김철수의 10/20 연차는 **유지**되고, 관리자에게 경고 문구가 보인다.

### 2-5. ❓ 아직 정할 것

1. **경고와 함께 원래 기간에 남은 휴가 명단을 보여 줄지**
   - 제안: 경고 아래에 이름·날짜·종류 명단을 보여 줘서, 관리자가 바로 직접 취소할 수 있게 한다.
2. **일부만 겹치는 휴가를 어떻게 처리할지**
   - 예: 10/1~10/2 신청(한 건, 2일), 금지 기간 10/2~10/7, 정책은 모두 취소

   | 방법 | 결과 |
   |---|---|
   | **A. 신청 건 전체 처리** (추천, 요청서 원문) | 10/1~10/2를 통째로 취소하고 2일을 환원한다. 10/1이 필요하면 직원이 다시 신청한다 |
   | B. 겹친 날만 처리 | 10/1은 남기고 10/2만 취소해 1일만 환원한다. 휴가 한 건을 나누는 기능이 새로 필요하다(결재 기록·기간 배정·캘린더·메일에 영향) |

   - 결재 대기 휴가도 같은 방식(A면 전체 반려)으로 처리한다.
3. **A라면 메일에 다시 신청하라는 안내를 넣을지**
   - 예: "겹치지 않는 날(10/1)이 필요하면 다시 신청해 주세요."
