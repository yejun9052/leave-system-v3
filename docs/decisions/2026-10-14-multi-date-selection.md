# 여러 날짜 골라 신청하기 (2026-10-14)

휴가 신청·일정 추가·강제 등록·블랙아웃 등록에서 날짜를 **클릭할 때마다 넣고 빼는 방식**(윈도우의 Ctrl+클릭과 같은 개념)으로 바꾼다. 참고: 이 프로젝트의 V2(`yejun9052/leave-system-v2`)의 달력 선택.

## 결정 (사용자, 2026-10-14)

| 항목 | 결정 |
|---|---|
| 클릭 방식 | 클릭 = 그 날짜 넣기/빼기만. 드래그·Shift 범위 선택 없음 |
| 저장 | **이어진 날짜끼리 신청 하나**, 떨어진 날짜는 신청을 따로 만든다. 신청 한 건은 지금처럼 시작일~종료일이라 DB 구조는 바꾸지 않는다 |
| "이어진" 기준 | 휴가·블랙아웃: 사이에 주말·공휴일만 있으면 이어진 것(금+월 → 한 건, 주말은 차감 안 함). 일정: 달력 날짜가 바로 이어져야 한 건(금+월 출장 → 2건) |
| 표시 | 이어진 묶음은 "10/11 ~ 10/13", 떨어진 날은 "10/11", 여럿이면 쉼표로: "10/11 ~ 10/13, 10/15" |
| 반차·시간차 | 날짜 하나를 골랐을 때만 |
| 일부가 규칙에 걸리면 | 전부 신청하지 않는다(한 트랜잭션). 어느 날짜 때문인지 알려 준다. 잔액은 앞 건이 쓴 일수까지 합쳐 본다 |
| 결재·취소 | 건마다 따로(지금과 같음) |
| 알림·메일 | 건마다 따로(지금과 같음) |

## V2 와 다른 점

- V2는 신청 하나에 날짜 목록(`leave_dates`)을 저장했다. 여기서는 이어진 묶음마다 신청을 나눈다.
- V2 목록은 "첫날 ~ 마지막 날"만 보여 중간이 빈 것이 가려졌다. 여기서는 신청이 묶음 단위라 생기지 않는다.
- V2는 반차를 고르면 고른 날 모두 반차였다. 여기서는 하루만.
