## 일부러 남긴 것

- **임시 비밀번호 유효기간 없음**: 새 직원에게 메일로 보내는 임시 비밀번호는 첫 로그인 전까지 계속 유효하다. 막으려면 DB 컬럼(발급 시각, V2 마이그레이션)이 필요해 **이번엔 하지 않기로** 했다(2026-10-13).

## ❓ 운영(설치·배포)에서 정할 것

- ❓ **admin 초기 비밀번호가 문서에 적힌 고정값(`admin1234!`)**: 설치 직후 운영자보다 먼저 접속한 사람이 비밀번호를 정하고 시스템 관리자가 될 수 있다. `install.sh` 가 무작위 값을 만들어 secret 으로 넣거나, 운영에서는 값이 없으면 기동하지 않게 하는 방법. `application-local.yml` 의 "운영은 무작위 생성" 주석은 지금 동작과 다르다.
- ❓ **앱이 DB 슈퍼유저로 접속**(`docker-compose.prod.yml` 의 `DB_USERNAME: ${POSTGRES_USER}`): 가져온(import) 백업에 `COPY … FROM PROGRAM` 이 들어 있으면 DB 컨테이너에서 명령이 실행될 수 있다. 같이 넣은 `.json` 으로 체크섬·버전 검사도 우회된다. 앱 전용 일반 계정을 쓰고, "가져온 파일은 믿을 수 있는 것만" 경고를 문서·복원 창에 넣는 방법.
- ❓ **모드 B(공인 IP + HTTP)**: 비밀번호와 30일 로그인 유지 세션이 평문으로 오간다. 사내망 전용이라고 적거나 HTTPS(`tls internal`)를 권장.
- ❓ Caddy 컨테이너가 root 로 실행, pg 클라이언트(`postgresql-client-16`) 최소 버전 미고정(16.10 미만이면 CVE-2025-8714).
