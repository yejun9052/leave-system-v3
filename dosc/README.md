2026-09-21 V02 갱신에는 운영 Google OAuth·dev 폼 로그인, 날짜별 USE/CANCEL, 경조사 종류·근속·종료일 계산, 공지 첨부, 역할별 API, 미처리 신청 목록·복원 절차를 반영했다. 취소요청·공지 첨부·미처리 목록은 MVP 포함이다. 이후 결정과 위험 검토는 다듬은 설계를 우선한다.

V01의 단일 ADMIN과 UNIQUE(request_id, type), 이전 V02의 USE:신청id 단일 키를 최신 기준으로 사용하지 않는다. 승인 컬럼의 ERD 누락, 경조사 max_days 의미, 음수 기간 리포트 산식 등은 V02 확인 항목을 참조한다.
